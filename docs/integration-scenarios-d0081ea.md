# Integration Scenarios

Explore the integration options for SAP Task Center. Unify all your tasks into one inbox by first connecting the task providers. After that you can also embed your tasks in the To-Do section in SAP Start or SAP Mobile Start.

Once you have completed the initial setup of SAP Task Center, integrate your task providers with SAP Task Center in two main steps. First, connect your task providers to aggregate all items into a single inbox and access them from the SAP Task Center Web app. Second, set up the integration with SAP Start and SAP Mobile Start to display your tasks in their *To-Do* sections.

-   Integrate SAP or non-SAP task providers with SAP Task Center to be able to provess your tasks from the SAP Task Center Web app.

    For more information, see [Integrate SAP Task Center with Task Providers](integrate-sap-task-center-with-task-providers-b158111.md).

-   Integrate SAP Task Center with SAP Start and SAP Mobile Start to access all your tasks from the To-Do sections.

    For more information, see [Integrate SAP Task Center in SAP Workspaces](integrate-sap-task-center-in-sap-workspaces-0c4c3ce.md).
