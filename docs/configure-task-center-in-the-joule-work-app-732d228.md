# Configure Task Center in the Joule Work App

The task center in the Joule Work mobile app allows users to review and process all their tasks from a mobile device.

For more information about setting up the task center in the Joule Work mobile app, see [To-Dos in Joule Work App - Administration Guide](https://help.sap.com/docs/joule-work-mobile/administration-guide-sap-build-work-zone-setup/to-dos).

> ### Note:  
> To use the *To-Dos* feature in Joule Work, you need to first set up SAP Task Center in the SAP Build Work Zone, standard edition.
